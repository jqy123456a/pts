# 重新开始（重开本场 / 重开整局）设计

> 功能：战斗中可「重开本场」（恢复进场前状态重打同一场）或「重开整局」（清空进度回选将界面）。

## 1. 目标与范围

- 入口：战斗系统按钮区（「放大/缩小」旁）新增两个按钮：「重开本场」「重开整局」。
- 重开本场：恢复到进入本场战斗前的状态（体力/金币/卡组/技能），重新打**同一场**（相同敌人）；无惩罚，纯重试。
- 重开整局：清空当前整局（进度/金币/卡组/技能/货单全作废），整页重载后回选将界面（全新开局）。
- 非目标：不在战斗外提供按钮；不保留任何进度于「重开整局」。

## 2. 关键机制（正确性依据）

- 战斗期间 `pts_run` 存档不被写入（`saveRun` 只在结算/地图时调用），故 `state.pending` 与「进场前快照」一直保留。
- 进战斗时 `pts_flow` 已被 `start()` 读取并 `removeItem`；故「重开本场」必须先用 `game.ptsFlowSave()` 重设 `pts_flow="battle"`，否则重载后 `flow !== "battle"` 会误走「继续冒险」分支回到选将界面。

## 3. 实现点

- 文件：`resources/app/src/pts/battle.js`（仅此一文件），`ptsTidyBattleUI()` 内与「放大/缩小」同一 `if (!game.ptsZoomButtons)` 守卫块。
- 两按钮文案与弹窗：
  - 「重开本场」→ `ui.create.dialog("重开本场", "确定重新开始本场战斗吗？(恢复到进场前状态)")`
    - 确定：`game.ptsFlowSave(); game.reload();`
  - 「重开整局」→ `ui.create.dialog("重开整局", "确定放弃本局并重新选将吗？")`
    - 确定：`game.ptsClearRun(); game.reload();`
  - 均用 `dialog.add([["确定", fn], ["取消", () => dialog.close()]], "textbutton")`；取消仅关窗。
- 依赖：`game.ptsFlowSave` / `game.ptsClearRun`（pts.js 已挂）、`game.reload`（引擎原生）。

## 4. 错误处理与风险

| 风险 | 处理 |
|---|---|
| 战斗中误点清档 | 两键均二次确认兜底；取消即无事 |
| 重开本场误走「继续冒险」 | `ptsFlowSave()` 重设 flow="battle"（见 §2） |
| 按钮重复添加 | 复用 `if (!game.ptsZoomButtons)` 防重复 |

## 5. 测试

- 无 node 单测（纯 GUI 交互）；验证靠手测清单：
  1. 战斗中出现「放大/缩小/重开本场/重开整局」四键；
  2. 「重开本场」→ 确认框 → 取消则继续、确定则重载后仍打同一敌人，体力/金币/卡组与进场前一致；
  3. 「重开整局」→ 确认框 → 确定则回到选将界面，`game.ptsLoadRun()` 为 null；
  4. 重开后地图为全新 15 层（首层战斗、9 层宝箱、15 层 BOSS 固定）。
